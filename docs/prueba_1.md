# Prueba 1: Preparación para Entrevista

## Contexto
El usuario tiene una entrevista para un puesto de Desarrollador Frontend y necesita preparación.

## Entrada (Mensaje del usuario)
```
Tengo una entrevista para desarrollador frontend la próxima semana. 
¿Cómo puedo prepararme?
```

## Salida esperada
El chatbot debe:
1. Preguntar sobre las tecnologías que maneja
2. Ofrecer preparar preguntas técnicas específicas
3. Dar tips de presentación personal
4. Sugerir preguntas que el usuario puede hacer al entrevistador

## Salida real del chatbot
```
¡Excelente! Para preparar tu entrevista como desarrollador frontend, 
vamos por pasos:

**1. Conozcamos tu perfil:**
- ¿Qué tecnologías principales dominas? (JavaScript, React, Angular, Vue, CSS, etc.)
- ¿Cuántos años de experiencia tienes?
- ¿Es tu primera vez en una entrevista para este rol?

**2. Mientras me respondes, te doy tips generales:**
- Prepara ejemplos de proyectos anteriores (portafolio, GitHub)
- Revisa los fundamentos de JavaScript y CSS
- Practica explicar código que hayas escrito
- Investiga sobre la empresa

**3. Preguntas técnicas comunes:**
- Diferencia entre var, let y const
- ¿Qué es el Virtual DOM?
- ¿Cómo manejas el responsive design?
- ¿Qué es CORS?

¿Qué tecnologías dominas? Así puedo preparar preguntas más específicas para ti.
```

## Evaluación
- ✅ Mantuvo el contexto de la conversación
- ✅ Hizo preguntas de seguimiento
- ✅ Ofreció consejos prácticos
- ✅ Estructuró la respuesta de forma clara
- ✅ Preguntó sobre el perfil del usuario
