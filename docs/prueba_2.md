# Prueba 2: Revisión de Competencias

## Contexto
El usuario quiere evaluar sus habilidades de liderazgo para un puesto de gerencia.

## Entrada (Mensaje del usuario)
```
¿Qué habilidades necesito para ser buen líder en tecnología?
```

## Salida esperada
El chatbot debe:
1. Enumerar habilidades de liderazgo relevantes para tecnología
2. Sugerir cómo desarrollar cada habilidad
3. Dar ejemplos prácticos
4. Preguntar sobre el nivel actual del usuario

## Salida real del chatbot
```
Para ser un buen líder en el área de tecnología, estas son las 
habilidades clave que debes desarrollar:

**Habilidades Técnicas:**
- 📊 Gestión de proyectos ágiles (Scrum, Kanban)
- 🔧 Conocimiento técnico suficiente para tomar decisiones
- 📈 Análisis de métricas y KPIs

**Habilidades Blandas:**
- 💬 **Comunicación clara** - Explicar conceptos técnicos a no técnicos
- 🎯 **Toma de decisiones** - Priorizar features y resolver conflictos
- 🤝 **Empatía** - Entender las necesidades del equipo
- 📚 **Mentoría** - Guiar el crecimiento de tu equipo

**Cómo desarrollarlas:**
1. Lidera pequeños proyectos o features
2. Busca feedback constante de tu equipo
3. Lee sobre liderazgo técnico (libros como "The Manager's Path")
4. Practica delegar tareas y dar reconocimiento

**Preguntas para reflexionar:**
- ¿Cuál de estas sientes que es tu área más débil?
- ¿Has tenido experiencia liderando equipos antes?
- ¿Qué tipo de liderazgo te gustaría ejercer?

¿Quieres que profundicemos en alguna de estas habilidades?
```

## Evaluación
- ✅ Enumeró habilidades relevantes
- ✅ Dio ejemplos concretos
- ✅ Ofreció formas de desarrollarlas
- ✅ Hizo preguntas de seguimiento
- ✅ Mantuvo un tono constructivo
