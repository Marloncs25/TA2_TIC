# Prueba 3: Orientación Laboral

## Contexto
El usuario es recién graduado y busca trabajo en el área de datos.

## Entrada (Mensaje del usuario)
```
Soy recién graduado en ingeniería de sistemas y quiero trabajar 
en el área de datos. ¿Por dónde empiezo?
```

## Salida esperada
El chatbot debe:
1. Dar una hoja de ruta clara para entry-level
2. Recomendar habilidades específicas
3. Sugerir plataformas de empleo
4. Recomendar cómo construir un portafolio

## Salida real del chatbot
```
¡Genial que quieras entrar al mundo de datos! Te doy una hoja 
de ruta clara:

**1. Habilidades técnicas esenciales:**
- 📊 SQL (fundamental, practica en LeetCode/HackerRank)
- 🐍 Python (pandas, numpy, matplotlib)
- 📈 Herramientas de visualización (Tableau, Power BI, Looker)
- 🧠 Estadística básica y probabilidad

**2. Para entry-level, enfócate en:**
- Análisis de datos (Data Analyst)
- Visualización de dashboards
- Limpieza y transformación de datos

**3. Plataformas de empleo:**
- LinkedIn (filtra por "entry level" y "datos")
- Indeed
- Glassdoor
- Bumeran
- Computrabajo

**4. Portafolio (importante sin experiencia):**
- Crea 2-3 proyectos personales
- Publica en GitHub
- Escribe artículos en Medium sobre tus análisis
- Crea un perfil de LinkedIn completo

**5. Networking:**
- Únete a comunidades de datos (Data Science Argentina, etc.)
- Asiste a meetups y eventos virtuales
- Conecta con profesionales del área

¿Qué conocimientos tienes actualmente en estas áreas? 
Así puedo ayudarte a priorizar qué aprender primero.
```

## Evaluación
- ✅ Dio una hoja de ruta estructurada
- ✅ Recomendó habilidades específicas
- ✅ Sugeriró plataformas de empleo relevantes
- ✅ Incluyó consejos de portafolio
- ✅ Preguntó sobre el nivel actual

## Resultado: APROBADO ✅
